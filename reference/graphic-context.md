## COPY RULES (on-graphic text)

- **Headlines:** 3–6 words max, Arial Bold, always White
- **Subtext:** 1 line, Arial Regular, `#A0A5B2`
- **Accent phrase:** `#329FCD` — ONE use per graphic max
- **Tagline:** "Whatever It Takes." — appears once per asset, never in the main headline
- **"WHATEVER IT TAKES" tag:** top-left, Arial Bold 12pt, `#329FCD`, tracking 0.08em — optional

### Approved headline patterns (from brand guidelines)
- "This Isn't a ____."
- "____. Anywhere."
- "The Details Nobody Notices."
- "Behind Every Great Event #__"
- "Not Your Average ____."
- "____. Whatever It Takes."

### Voice rules
- Short and contrast-driven (expectation vs reality, problem vs solution)
- Values-led — each post should quietly reflect Safety, Responsible, Agile, or People First
- Never promotional — let the photo/number do the work
- Never: corporate fluff, "pleased to announce", "world-class"

## SESSION WORKFLOW

1. User gives post ideas (rough is fine)
2. For each idea I output:
   - **Template** (A / B / C)
   - **On-graphic text** — headline + subtext + cyan accent line (if needed)
   - **Visual brief** — photo needed or pure graphic, what the background shows
   - **Caption** — platform-ready copy
3. JPEG previews generated
4. User builds in Photoshop using PHOTOSHOP_EDIT_NOTES.md

### Mix rule per session
Vary backgrounds — don't stack 4 dark navy posts.
Suggested mix for 4-post sessions: 2× photo (Template A) + 1× Stat/pure graphic (B) + 1× Info graphic (C)
