## BRAND COLOURS — Save these as Swatches before starting

| Name | Hex | Primary use |
|---|---|---|
| Deep Navy | `#183057` | Primary backgrounds, headlines |
| Near-Black Navy | `#0C172C` | Darkest BG, gradient base |
| Bright Cyan | `#329FCD` | Accent — one use per graphic only |
| Brand Blue | `#0071B7` | Secondary colour, links, tiles |
| Neutral Grey | `#72747E` | Dividers, secondary text |
| White | `#FFFFFF` | Text on dark, fills |
| Subtext Grey | `#A0A5B2` | Captions, supporting text |
| Navy Tint | `#253048` | Card/tile backgrounds |

> **Hierarchy rule:** Deep Navy is primary. Bright Cyan is the accent — use it for ONE thing per graphic only (the number, the CTA, or the tag — never all three at once).

## TYPOGRAPHY

**Font: Arial only** (it's a system font — no download needed)

| Weight | Use |
|---|---|
| Arial Bold | Headlines, subheads, emphasis |
| Arial Regular | Body copy, captions, subtext |
| Arial Italic | Quotes, emphasis variant |

**Size rules for 1080×1080 canvas:**
- Social post headlines: 72–96 px
- Subtext / supporting copy: 28–36 px
- Captions / labels: 20–26 px
- Never below 18 px on a social graphic

## POST 1 — "This is the standard."
**Photo: Mannequin in Al Laith uniform | Template: Photo-Forward**

### Layer stack (bottom → top):

**1. Background photo**
- Place mannequin photo, scale to fill 1080×1080
- Keep mannequin centred or slightly right

**2. Bottom gradient overlay**
- New layer above photo
- Fill: `#0C172C` (solid)
