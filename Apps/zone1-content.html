Anthropic API Key

Add your Anthropic API key to unlock AI features: caption writing, hook suggestions, hashtag generation, and content idea generation.

Your key is stored only in this browser (localStorage) and is sent directly to Anthropic — never via any third-party server.

Data Management

All posts and series are stored in your browser’s localStorage. Export for backup before clearing browser data.

How to Get an API Key

1. Visit console.anthropic.com
2. Sign in or create a free account
3. Go to API Keys in the sidebar
4. Click Create Key
5. Copy and paste the key above

Cost note: AI features use Claude Haiku (fastest and most affordable model). A typical content session costs less than $0.01 USD.
